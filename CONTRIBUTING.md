# Contribuir a Ruido

El repositorio es público. La documentación debe describir el producto, su implementación, decisiones técnicas y comprobaciones reproducibles.

Antes de publicar cambios, revisar el diff y los archivos añadidos. No incluir credenciales, tokens, claves, datos personales, exportaciones de escenas, conversaciones ni notas operativas privadas. Las credenciales necesarias para automatizaciones se configuran como secretos del servicio correspondiente, nunca en el código o los ejemplos.

Los documentos de especificación y decisiones se mantienen junto al código. Las limitaciones de validación se indican de forma explícita; no se presentan pruebas pendientes como realizadas.

Los audios nuevos requieren fuente, autor, licencia y modificaciones documentadas en el catálogo y en las atribuciones. La licencia del código no sustituye las licencias de audio ni dependencias.
