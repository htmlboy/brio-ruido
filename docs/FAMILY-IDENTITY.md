# Ruido within the Brío family

## Identity

Use the canonical independent Ruido wordmark, without an added dot or “by Brío”. The reverse SVG uses the same outlined master as the family specimen. The separate Brío mark in the footer links to the project directory. Public author: Javier U. Contact: Discord username `javier_u`.

## Shared language, tool-specific layout

Ruido remains an audio tool. Retain the scene illustrations, library rows, sticky playback controls, desktop mixer and mobile mixer access. Do not import a marketing cover or the directory's three-column layout. IBM Plex Sans is hosted locally with its SIL OFL text; metadata and controls use the same family as the other Brío websites.

A warm dark surface (#20221e), warm panel (#292c26) and paper-coloured text (#f3efe4) relate to the directory's paper and ink. Primary actions use the family red (#b43824); smaller active indicators use a lighter tint (#e7a08c) for contrast on dark surfaces. Muted text is #b3b6aa. Text contrast calculations: body 13.96:1, muted text 7.78:1, active tint on panel 6.61:1, primary-button label 5.18:1. These pair checks do not constitute a complete accessibility audit.

Remove the joined outer scene grid, bordered tone chips, mixer outline and footer rule. Keep boundaries for inputs, playback transport and dense track rows where they identify controls or aid scanning. Active scenes and playing tracks retain visible state indicators. Illustrations still identify scenes; this revision does not change artwork or audio selections.

## Responsive behaviour

At narrow widths, the wordmark and help button share the first header row and the two navigation entries use a second row. This avoids shrinking the identity or crowding navigation at 320 px. Playback and stop remain visible. The horizontal scene strip and mobile mixer retain their existing behaviour.

## Scope

No changes to the audio engine, catalogue, saved-data schema, track IDs or scene definitions. The empty mixer omits the redundant unnamed-mix heading until a track is selected. Keep font and audio attributions with their respective licenses. Do not introduce external font or image requests.

## Compact header sizing

Ruido uses a 90 px wordmark on desktop and 76 px on mobile. The link target stays at least 44 px high. Library navigation fits on the same row above 360 px; narrower screens retain the two-row header. This reduces branding height without shrinking controls.
